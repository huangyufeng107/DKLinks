1. 场景目标与交付范围

总部日产项目通过排期配置供应商账号、预算、固定成本价与销售价、SmartCode和关联专营店（后者本期不参与过滤）。平台完成必要接收校验及号码检测，按供应商传入的意向门店一发一至NEV，结合付费明细与宽表结果查看费用和效果。

本轮新增的核心能力是“有效锁单达标停发”：运营按排期开启，系统计算目标，全部供应商合计达到目标后停止该排期尚未发出的线索。

4. 正常、停发与恢复流程

先审查业务流程：打开正常下发、停发恢复与计费统计流程图 →。流程图用于核对分支和遗漏，具体口径仍以本需求说明为准。
  1. 配置排期维护账号预算；按需开启本规则，填写预期供应量、转化率。
  2. 自动计算目标按乘积向上取整；不影响原有计费公式。
  3. 累计有效锁单量合并同排期供应商结果；读取既有有效锁单口径。
  4. 下发前检查未停发且未达标，继续既有下发校验；达标则停发并保存原因。
达标分支

有效锁单量≥目标 → 保存排期停发状态 → 尚未发送的线索留存并标记“排期有效锁单目标已达成” → 已发出请求继续跟踪回执。

恢复分支

回落、提高目标或关闭开关均不自行恢复 → 运营核对 → 单独确认恢复 → 记录恢复时间／批次 → 后续新接收线索按当前条件处理，历史达标暂停记录不自动重发。

本流程增加排期级下发闸口，不替代鉴权、来源ID、黑名单、门店、品牌能力、排期时间及请求防重等检查。恢复只解除本规则停发，不代表所有其他限制已通过。

实现可复用现有下发入口；无需为停发批量重写所有未发送记录。但已被拦住的线索必须保留本规则暂停事实，不能在恢复后被既有重试任务无意发送。
