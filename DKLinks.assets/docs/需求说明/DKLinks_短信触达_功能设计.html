1. 功能入口

建议在「培育引擎」新增「短信触达」，包含 AI 短信规则、批量导入、短信模板库、短信下发记录四个页签。品牌运营在授权品牌内配置、导入和查询；查询权限与发送、启停、模板编辑权限分别授予。

现有 AI 外呼话单提供来源和结果依据；线索下发到门店及其报表口径继续沿用现行规则。已同步至 v1.2.5 本地原型。页面及模拟边界见 功能说明 与 版本日志。

2. AI 短信规则

列表按品牌、AI 线路和启用状态筛选。每行显示名称、优先级、条件摘要、发送动作、模板、状态和更新时间；支持查看、新建、编辑、启停。新规则默认停用。

配置项操作与校验
品牌与 AI 线路先选品牌，再选该品牌可用线路。更换品牌或线路时清除失效选项，按新范围重选标签、车系和模板。
标签按线路展示可选标签，按稳定标签编码匹配。包含标签可选满足任一或全部；可选排除标签，命中任一排除标签则本条不命中。至少选择一个包含标签。
车系 ID按品牌多选车系，界面显示名称及 ID，有选项时按任一 ID 命中。数据来自该话单关联的线索；不选择则不限。已限制车系而线索未记录 ID 时，本条不命中。
通话时长单位为秒，支持仅填下限、仅填上限或填写闭区间，端点均包含。校验非负整数且下限不大于上限。留空则不限；已配置而话单缺失时长时，本条不命中。已明确记录的 0 秒可参与比较。
动作与优先级各类条件同时满足才命中。动作可选「发送短信」或「不发送」；发送须选本品牌可用模板。建议同品牌、同线路的启用规则优先级唯一，数字越小越优先。只执行第一条命中的规则；不发送、去重拦截、模板不可用均不继续尝试低优先级模板。

在收到有效的最终通话话单后判断。同一次通话的重复回传只处理一次；规则使用本次判定时的生效配置，记录所用版本。通话标签和时长须取自同一通话记录，按外呼任务记录的品牌及线路匹配，不用一个任务里多次通话的字段拼接判断。

3. 批量导入短信

选择品牌和模板下载并上传名单校验预览确认发送查看批次结果

建议一期使用 Excel 模板，手机号为必填。手机号按文本读取并按统一口径规范化；预览显示脱敏号码、文件行号和处理原因。校验结果分为「可发送」「格式错误」「批次内重复」「近 72 小时已发送」「发送状态待核对」。同一批归一后的同号仅首条有效行可进入发送。

预览展示品牌、模板内容和各类条数，可下载有问题的行。无可发送项时不可确认。确认时冻结批次和模板内容，由系统异步执行；重复点击不会生成第二个批次。执行每一行时重新检查模板可用性、号码状态和 72 小时记录，实际结果以批次记录为准。

4. 短信模板库

按品牌查询，列表展示模板名称、内容摘要、状态、关联规则数和更新时间。支持新建、预览、编辑、启停；模板须绑定短信通道认可的签名及模板标识后方可用于发送。本期建议用固定正文，名单不支持自由填写短信内容。

停用前展示影响的规则；已停用模板不能新增引用，也不会继续发送。编辑生成新版本，已生成的发送记录保留当时使用的版本和正文；已确认的待发记录使用冻结内容，发送前若对应模板已停用，则跳过并记录原因。

5. 短信下发记录

按时间、品牌、来源、模板、状态及手机号查询，支持从批次列表下钻。列表显示记录时间、脱敏手机号、来源、模板和处理结果；详情显示执行时间、去重原因、通道回执以及规则版本和话单，或批次编号和操作人。待核对记录可由有权限人员查看处理依据；跨品牌去重只显示拦截原因。

状态界面含义
待发送／提交中已进入发送队列，或正在等待通道确认。
已受理／已送达通道已接受请求；收到明确送达回执后显示已送达。72 小时从受理时刻开始。
发送失败区分通道明确未受理和受理后送达失败。前者不占 72 小时，后者仍占用原窗口。
已跳过已命中不发送、近 72 小时已发送、模板不可用等，展示具体原因。未命中规则的判定保留在话单关联结果，便于核查。
待核对请求超时且无法确认是否受理；对账前不自动补发，也不放行同号的另一条请求。

6. 72 小时内只受理一条

平台按规范化后的手机号查询，AI 和导入共用，同号跨品牌也适用。距离最近一次已受理不足 72 小时时拦截；到达整 72 小时可重新按当前业务条件判断。示例：周一 10:00 受理，周四 09:59 拦截，周四 10:00 可以重新判断。

发送前须对同号请求做并发控制。两个入口同时触发时，只能有一个向通道提交；明确未受理可释放，结果待核对时保留占用，核对到受理则用原受理时刻起算，核对到未受理则释放。补发或后续重试也走同一限制。

8. 验收与联调

场景通过条件
品牌、线路与组合条件同标签但品牌、线路或车系不符时不发；通话时长等于区间端点可命中；所需字段缺失不命中。
规则冲突与话单重放同时命中两条时只执行最高优先级；最高优先级为不发送时不落到下一条；重复回传不产生第二次发送。
导入确认与并发未确认无发送；重复确认只生成一批。预览后同号被 AI 触达则实际跳过；两个入口同时触发只提交一次，规范化后同号同样拦截。
72 小时与异常回执71 小时 59 分拦截，达到整 72 小时重新判断。明确未受理不占用；已受理后未送达仍占用；受理不明进入待核对，同号不会被自动补发。
模板与权限停用模板不可继续发送；修改模板不改变历史正文。跨品牌无权限查看号码或发送细节，跨品牌去重仍生效。

联调需核实真实话单的事件唯一标识、线路标签字典、车系 ID 来源、通话时长字段、手机号规范化方案，以及短信通道的受理时间、结果查询和请求去重能力。确认回执契约后再定对账时效与告警。
